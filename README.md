# Personal Portfolio

A React + Vite portfolio for Rishav, featuring an LLM security hero, a photo-led About section, repository cards, and selected research.

## Run locally

```sh
pnpm install
pnpm dev
```

Open [http://localhost:4173](http://localhost:4173).

## Personalize

- Replace `src/assets/rishav-profile.jpg` to update the portrait.
- Update repository names and URLs in the `repositories` list in `src/App.jsx`.
- Add paper links and update descriptions in `src/components/Papers.jsx` when they are ready.
